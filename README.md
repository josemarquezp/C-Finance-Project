Income & Taxes Tracker – User Instructions

Enter an income source (example: Freelance, Job, Side Hustle).
Enter the income amount.
Click the “Push” button to calculate:
Tax amount (24%)
Income after taxes
Remaining income

Expenses:
Expenses are loaded from a file called expenses.txt.
This file must be in the same folder as the program (usually the bin/Debug folder when running in Visual Studio).

To add expenses, open expenses.txt and write them like this:

Rent 1200
Food 300
Gas 150

Each line should have a name and an amount separated by a space.
The program will automatically add all expenses and display the total.

Note: Expenses cannot be added directly in the app. They must be added in the expenses.txt file.

The program will also:
Save income to income.txt
Save income after taxes to incomeAfterTaxes.txt
Click “Clear” to reset inputs.
Click “Exit” to close the program.
